9. GLOBAL PAGE TRANSITIONS
==================================================

Every route should have smooth animated transitions.

When navigating:

Current page:
Fade out + subtle upward movement.

New page:
Fade in + subtle upward reveal.

Use AnimatePresence.

Transition duration:
Approximately 0.4–0.7 seconds.

Scroll to top when navigating to another page.

Do not make navigation feel slow.

==================================================
10. SCROLL REVEAL SYSTEM
==================================================

Almost every major section should have subtle scroll-triggered animation.

Implement reusable reveal components.

Effects can include:

- Fade upward
- Fade sideways
- Staggered children
- Scale reveal
- Clip-path reveal
- Text mask reveal

Trigger when elements enter the viewport.

Use IntersectionObserver or Framer Motion whileInView for simple reveals.

Use GSAP ScrollTrigger for complex sequences.

Animations should run smoothly and should not repeatedly trigger unnecessarily.

==================================================
11. PARALLAX SYSTEM
==================================================

Use parallax scrolling selectively across the website.

Use in:

- Hero sections
- About quote/banner
- Case study visual panels
- Sports Technology hero
- Industries hero
- Large background imagery
- Layered abstract graphics

Different visual layers should move at slightly different speeds.

Avoid aggressive parallax that causes motion sickness.
